# STEM. Шкільний діагностичний інструмент — План розвитку проєкту

## 1. Огляд проєкту

**Мета:** Цифрова платформа для діагностики зацікавленості учнів 5–9 класів у STEM-дисциплінах на основі опитувальника STEM Semantics Survey та моделі класу.

**Ключові компоненти:**
- STEM Semantics Survey (5 блоків, 25 питань, шкала 1–7)
- Модель класу (ранжування S, T, E, M) та **розширена модель за статтею** (К1–К5, `ranking_article`)
- Методичні рекомендації для педагогів
- Аналітика для завучів та директорів (агрегати, порівняння двох опитувань, експорт CSV/XLSX)

## 4. Ролі та права доступу

| Роль      | Доступ |
|-----------|--------|
| Учень     | Проходження опитування, свої класи з `class_students` |
| Вчитель   | Результати свого класу, модель класу, рекомендації |
| Завуч     | Усі класи школи, порівняльна аналітика, експорт |
| Директор  | Як завуч для своєї школи |
| Адмін     | Школи, аналітика по будь-якій школі |

---

## 5. Технічний стек

- **Backend:** Python + FastAPI
- **Frontend:** статичні HTML/CSS/JS
- **БД:** PostgreSQL
- **Автентифікація:** JWT + bcrypt
- **Міграції:** Alembic
- **Тести:** pytest + PostgreSQL (локально або CI)
- **Moodle:** Questionnaire / експорт CSV → імпорт у БД

---

## 6. Критерії прийняття

1. Опитувальник коректно імпортується в Moodle
2. Результати зберігаються в БД
3. Модель класу розраховується автоматично (у т.ч. варіант «за статтею»)
4. Завуч/директор бачить агреговані дані та може порівняти два опитування
5. Система захищена від базових атак; CI проганяє тести
